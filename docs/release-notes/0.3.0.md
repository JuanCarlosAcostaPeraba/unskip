# Unskip 0.3.0

Unskip 0.3.0 improves destination compatibility and introduces the first safe, local-only preview of the planned urgent-attention experience.

## Highlights

- Canonical IPv4 destinations now use reverse DNS and forward verification to obtain the Windows computer name required by `msg.exe`.
- The message composer can preview the current validated draft in a full-screen urgent-attention design on the sender's own computer.
- The preview covers the Windows virtual screen, including negative monitor coordinates, declares per-monitor DPI awareness, and keeps its message card wholly on the primary monitor.
- A fixed close button, Escape, Alt+F4, display-topology closure, and a one-minute timeout keep dismissal predictable.

## Important boundaries

The urgent-attention experience in this release is a local preview only. It does not contact or install anything on a recipient computer, listen on a network port, change firewall or startup settings, persist the draft, or claim that a message was displayed, read, or acknowledged.

Native Windows messaging remains subject to DNS, reachability, active sessions, permissions, and organizational policy. A successful native request is not a read receipt.
